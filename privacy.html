PRIVACY BY DESIGN

Your imported files stay local in the current static edition unless you choose an external integration.

The GitHub Pages version of AI.IQ is designed as a local-first browser application. Its default data-import and analysis workflows operate in the browser, which reduces the need to upload raw social media exports to a separate AI.IQ server.

Open AI.IQ →

Local browser processing

CSV, TSV and JSON imports are parsed in the browser. Workspace state is stored using browser storage where available. Clearing browser storage or using the application’s clear/reset controls can remove that local state.

Optional external integrations

The Integration Center can be configured by a user to call an external AI endpoint or publishing webhook. If a user chooses to configure one, information sent to that endpoint is subject to the policies and security of that external service. AI.IQ does not silently connect those services by default.

What not to upload

Do not place passwords, authentication secrets, payment-card data or other unnecessary sensitive information inside exported files. Export only the fields needed for the analysis you intend to perform.
